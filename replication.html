02 / Agent workflow

From research instructions to checked results

The existing research workflow separates the agent’s analysis from the evaluator’s reference answers.

  1. 1

    Input: the task and research data

    The agent receives the analysis instructions and declared data: the requested effect, estimation method, variables and any sample or standard-error requirements. Reference answers and reference programs stay with the evaluator.

  2. 2

    Execution: inspect, program and revise

    Through a harness, the agent inspects the data, writes and runs an analysis program, and can revise it using execution feedback. The requested output includes the coefficient, standard error and p-value.

  3. 3

    Independent check: compare the result

    The final program is run independently and its numerical output is checked against the reference. This check is separate from the agent’s own inspection and revisions.

This describes the recorded research workflow. The formal Challenge evaluation rules will be announced with the release.

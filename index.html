The benchmark

InferenceNet — published findings as replication tasks

2,644 replication tasks drawn from 36 journals across 6 disciplines. Each task packages a published finding as its research data, the estimation method, the controls and requirements, and the target statistic. The paper's reference answer and reference program stay on the scorer side; the model sees only the instruction and the data.

01 / The question

Run the analysis, reproduce the finding

A task is a published result with its research data attached. The agent receives the estimation method, the outcome and treatment variables, the controls and the paper's requirements, writes and runs a program, and returns one coefficient, its standard error and its p-value. An independent scorer compares that triplet with the published values; the reference answer and the reference program are never shown to the model.

03 / Tasks

Six real tasks from Selected_1000

Each tile is a task from the pinned task list: the plain-English question, the estimation method and the journal. Reference values stay withheld except for tasks 0001 and 0011, which the Data and Agent pages walk through in full.

  • Task 0001 Panel OLS

    Consumption smoothing in interwar Japan

    How much does a working-class household's consumption move when its disposable income changes? A monthly household panel with household and month-year fixed effects, composition controls interacted with quarter dummies, and household-clustered standard errors.

    Journal of Economic HistoryOpen the case →

  • Task 0011 Real runOLS

    Economic uncertainty and divisive politics (the ‘two Spains’)

    How does socio-economic conflict relate to economic policy uncertainty, 1905–1945? OLS with month-clustered standard errors.

    Journal of Economic HistoryWatch the run →

  • Task 0104 DID

    Deterrence and compellence in parliament

    Did lifting an MP's immunity change how often they submitted formal queries to the government? A difference-in-differences with MP and month-by-year fixed effects, clustered by MP.

    The Journal of Law and EconomicsOpen the case →

  • Task 0100 IV-2SLS (fuzzy RDD)

    Patent validity and litigation

    Does filing an inter partes review make a case more likely to settle? A fuzzy regression discontinuity around the one-year filing deadline, estimated as an IV/2SLS second stage with a triangular kernel and case-clustered errors.

    The Journal of Law and EconomicsOpen the case →

  • Task 0145 RDD

    Liquidity effects of litigation risk

    How did a legal shock change firms' cash holdings? A local-linear regression discontinuity at the cutoff with a triangular kernel, clustered by company.

    The Journal of Law and EconomicsOpen the case →

  • Task 0194 Probit

    Incentives in non-routine analytical team tasks

    Does a bonus incentive change behavior? A probit model on the field (non-laboratory) sample.

04 / Harness

Two ways to solve the same tasks

Each of the six models is evaluated on the same 1,000 tasks in two settings. Both receive the task and data; reference answers remain hidden.

  • Model only

    Generate once, execute once

    One model call produces one program, which is executed once to return the result.

  • Model + DeepAgents

    Inspect, execute, refine

    The model can inspect data and revise its program using execution feedback, with up to 6 model calls and 4 tool executions per task. The final program is replayed in a clean container.

The two settings use different inference budgets. All 1,000 planned tasks remain in each score's denominator.

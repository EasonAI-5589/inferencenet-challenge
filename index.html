# Translate the question into a specificationpanel = read_data(task.data)states = above_median_population(panel, year=1982)sample = panel.for_states(states)y = log(sample["fatality_rate"])spec = EventStudy(treatment="primary",    lookback=4, lookforward=3, controls=[],    fixed_effects=["state", "year"], cluster="state")fit = staggered_did(sample, y, spec,    estimator=task.estimator)result = extract(fit, target="Lag_D1")emit_json(result)

PROPENSITY-SCORE REGRESSION ADJUSTMENT

How does maternal smoking affect birthweight?

Adjust for observed covariates and trim both score tails before regression.

Published example §V ↗

INPUT / INDIVIDUAL RECORDS

tobacco
Smoking treatment
dbrwt
Birthweight outcome
19 specified covariates
Including 6 categorical fields

DESIGN / SCORE QUANTILES

10%Retained sample10%
TrimTrim
ANALYSISIllustrative pseudocode
# Preserve the requested adjustment methodrows = prepare_aligned_rows(task.data)X = encode_categories(rows[task.controls],    columns=task.categorical_fields)score = logit(rows["tobacco"], X, intercept=True)score = score.predict_probability()lo, hi = quantile(score, [0.10, 0.90])kept = rows.assign(score=score)[score.between(lo, hi)]fit = ols("dbrwt ~ tobacco + score",    data=kept, intercept=True)result = extract(fit, target="tobacco")emit_json(result)

Covariates follow the source prompt; trimming uses score quantiles.

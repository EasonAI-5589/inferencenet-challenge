Three tracks, sixteen classes

The challenge follows the Metacase classification in metacase-harbor v0.1: each track is a field, split into classes of tasks.

Track 01152 tasks · 5 classes

Economics

From published research to live data: replicate empirical estimates, read central-bank language, forecast market moves and build economic datasets.

  1. econ.replication

    Econometric replication

    100 tasks

    Reproduce a published regression coefficient from the paper's own data.

    Subtrack 01Dev100 · 100 tasks

    Reproduce empirical findings from real research data. An AI agent writes and runs code to recover a published coefficient, its standard error and its p-value.

    Research data on Hugging Face

    The research dataset collects empirical research tasks from economics, finance, accounting, management, operations research and information systems. Task packages combine research data, analysis instructions and reference replication materials.

    The Hugging Face repository provides the dataset card, task lists, files and citation information.

    Open the dataset on Hugging Face ↗

    Files require signing in to Hugging Face and accepting the repository’s access conditions.

    Dev100: 100 econometric replication tasks

    The econometric replication challenge will open-source the existing Dev100 task set. Agents inspect the data, implement the specified analysis and submit results for independent evaluation.

    Explore Dev100 / v10 development results →
    Input
    The research data and the exact instruction the model receives.
    Output
    A result file with three numbers: the coefficient, the standard error and the p-value.
    Evaluation
    An independent evaluator checks the three numbers against reference results that the model never sees during the run.
    Explore Subtrack 1 → Explore improvement directions →
  2. econ.data

    Economic & business data engineering

    22 tasks

    SQL and dbt over banking, retail, e-commerce and wholesale supply-chain data.

  3. econ.markets

    Market movement forecasting

    15 tasks

    Predict stock price movement from tweets and historical prices.

  4. econ.monetary

    Monetary policy communication

    15 tasks

    Classify the hawkish / dovish stance of FOMC statements and minutes.

  5. econ.statistics

    Official statistics synthesis

    0 tasks

    Gather and combine figures from statistical offices and international organisations into a structured answer.

  1. fin.nlp

    Financial text understanding

  2. fin.accounting

    Accounting close & finance deliverables

    15 tasks

    Month-end close remediation and accounting data pipelines.

    Subtrack 02Finance & HR

    Business Analysis & Deliverables

    Complex business scenarios contributed by Prof. Liwen Zhang’s team at Shanghai University of Finance and Economics. Agents work across multiple source documents to produce reports and spreadsheets, assessed against task-specific rubrics.

  6. fin.filings

    Financial research & filings QA

System view

From task to score

Each challenge runs through three layers: the task and its data, the agent's workspace, and an evaluation the agent never sees. Hover a layer to trace it, or drag the model to turn it.

  1. L1

    Tasks and data

    Challenge 1 asks for an empirical result from a research specification; Challenge 2 asks for business deliverables from multi-file records.

    • Replication
    • Deliverables
    • Data files
  2. L2

    Agent workspace

    A model works inside a harness that supplies context, tools and feedback, and runs its code in a sandbox.

    • Model
    • Harness
    • Sandbox
  3. L3

    Independent evaluation

    Submissions are checked against withheld reference values or a task rubric before results are compared.

04 / Take part

Ways to get involved

Explore a challenge, build an agent, or contribute tasks, evaluation and training research.

  1. Explore a challenge

    Review the task goals, source materials, expected deliverables and evaluation criteria to find a challenge you want to work on.

    In development

  2. Propose a new challenge

    Bring a new domain or problem to the initiative. Define the scenario, goals, expected deliverables and how a successful solution can be verified.

    Submit a benchmark →

  3. Build an agent

    Configure a model, tools and a harness to tackle a challenge. Plan the workflow, run the analysis and check the resulting deliverables.

    Submit an agent / harness →

  4. Contribute tasks and data

    Enrich an existing challenge with task examples, input materials and reference results. Help document the sources and make the tasks reusable.

    In development

  5. Improve evaluation

    Review scoring criteria, analyze failure cases and improve independent verification. Help make evaluations reproducible and comparisons meaningful.

    Submit a failure case →

  6. Study training and improvement

    Investigate how execution traces and feedback can improve model training and harness design, and test the resulting methods on new tasks.

    In development

Evaluation protocol, metrics and ModularRSI update

Tasks and four baseline harnesses

Dev100 comprises 100 econometric replication tasks from Selected_1000 (dataset revision 59f9512). Every combination evaluates 14 models across four harness configurations: DeepAgents 0.7.13, DeepSeek Harness 0.1.5rc1, Claude Agent SDK 0.2.165 (Claude Code CLI 2.1.294) and an OpenAI Agents SDK 0.23.1 runtime, under shared per-task caps of 6 model calls, 4 run_python tool calls, 32,768 output tokens and 1,800 s wall time.

ModularRSI-evolved DeepAgents (67.0%)

Applying ModularRSI self-evolution to DeepAgents (evolving loop, tool-use, completion and LangGraph ToolNode observation-audit feedback) raises GPT-5.6 Sol from 64.0% to 67.0% strict replication on a fresh paired Dev100 run (98% compilation, 78% partial replication, 95% correct sign, 81% significance), matching the top 67.0% score on the board. Explore the ModularRSI results →

  • Full replication: coefficient and standard error within 1% relative error; p-value within 0.01 absolute error (local-paper-v1).
  • Coefficient and SE within 5%: coefficient and standard error both within 5% relative error.
  • Coefficient within 5%: coefficient relative error at most 5%.
  • Correct sign: estimated coefficient and reference share the same sign.
  • Correct significance: correct sign and the same p-value threshold band (p < 0.01, 0.01–0.05, 0.05–0.1, ≥ 0.1).

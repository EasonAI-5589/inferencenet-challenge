Metric definitions

Compilation Success
Generated econometric code executes completely without runtime or syntax errors.
Partial Replication
The target treatment coefficient can be reproduced within a 5% relative error threshold.
Correct Coefficient Direction
The sign of the treatment-effect coefficient matches ground-truth results.
Significant Level Correctness
The model correctly reproduces the statistical significance level of the treatment-effect coefficient.

03 / By approach

The approach moves the score more than the model

Hold the model fixed and change the approach around it: GPT 5.5 reaches 26.4% Partial Replication inside Codex against 12.1% with plain Python; DeepSeek V4 Pro reaches 32.8% against 8.4%. On this snapshot, changing the approach for one model spans 19.9–27.1 points of Partial Replication; changing the model for one approach spans 6.4–17.0 points.

06 / Protocol

How the internal study was run and scored

One question drives every internal run: does the same model reproduce more InferenceNet findings when wrapped in a fixed Deep Agents harness than when generating a single program? The settings below are shared by every arm and every model; reasoning effort and execution environment differ by model, as the caveats record.

Paired-study protocol: settings shared by every model and both arms.
ItemSetting
DatasetCamoAiLab/InferenceNet @ 59f9512 · Selected_1000/1000_new.csv (1,000 tasks)
Baseline armsingle generation → one program → executed once
Deep Agents armDeep Agents 0.7.13 loop with run_python; final program replayed in a clean container
Model calls per task1 for the baseline · up to 6 for Deep Agents, with up to 4 run_python executions
Token and time budgets32,768 output tokens · 600 s wall-clock per task · 90 s execution per run
Container6 GiB RAM · 2 CPU · no network
Scoringlocal-paper-v1 diagnostic profile; reference values never visible to the model
Denominatorall planned tasks stay in the denominator; failures and unknowns are not removed

Caveats

  • Internal, exploratory comparison; not official leaderboard submissions and not verified for parity with the public scorer.
  • Sol and Opus runs are complete over 1,000 tasks; GPT-5.5, DeepSeek and Kimi numbers are interim statistics over completed pairs only.
  • Arms are not cost-matched: Deep Agents uses up to 6 model calls and 4 tool executions per task.
  • Reasoning effort and execution environment differ by model: effort high for GPT-5.6 Sol, Claude Opus 4.8 and GPT-5.5, provider default for DeepSeek V4 Pro, max for Kimi K3; the Kimi K3 interim run used chat streaming; the full runs, the interim runs and the pilots ran in different execution environments. Only the within-model pairs are like-for-like.
  • Model identities are request/response identities from the configured gateways.
